# 手动 URL 仓库持久化

当仓库平台无法通过 API 列出仓库或分支时，Wegent 支持通过 clone URL 手动添加仓库。

## 适用场景

以下场景适合使用该能力：

- `icode` 仓库无法通过 REST API 列出
- `Gerrit` 实例不提供可用仓库列表接口
- 用户已经知道完整 clone URL，希望直接开始任务

## 行为说明

通过 `通过 URL 添加仓库` 添加的仓库会被保存到当前用户的偏好设置中。

这意味着：

1. 刷新页面后仍然可见
2. 重新登录后仍然可见
3. 在同一账号的其他设备上也可见

## 添加步骤

1. 打开 Code 页面
2. 点击仓库选择器
3. 点击 `通过 URL 添加仓库`
4. 输入 clone URL
5. 可选输入目标分支
6. 点击确认

确认后：

- 当前任务会立即选中该仓库和分支
- 该仓库会加入你的手动仓库列表，后续可再次选择

## 当前限制

当前版本仅支持以下能力：

- 持久保存手动仓库
- 在仓库选择器中恢复显示

当前不支持：

- 删除手动仓库
- 编辑手动仓库名称
- 自动同步远端分支列表

对于 `icode / Gerrit` 手动仓库：

- 可以手动指定分支
- 也可以留空，届时会使用远端默认分支进行 clone

## 说明

手动仓库属于“用户偏好中的补录仓库入口”，不是通过 Git Provider API 自动发现的标准仓库记录。

因此它更适合作为：

- 常用内网仓库入口
- 临时无法枚举的私有仓库入口
- 通过 URL 直接发起任务的补充方式
